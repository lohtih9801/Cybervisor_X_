# CYBERVISOR-X: Frontend Web Application

The frontend user interface for the **CYBERVISOR-X** AI Threat Intelligence Platform, built with **React 19**, **Vite**, and styled with custom responsive design systems.

---

## 🚀 Key Modules

- **ATT&CK Matrix (`/`):** Full interactive MITRE ATT&CK enterprise navigator and threat tactics explorer.
- **Security Dashboard (`/dashboard`):** Real-time analytics, risk indicators, severity breakdowns, and quick action cards.
- **Deep Threat Analysis (`/analysis`):** In-depth inspection of threat indicators and vulnerability behaviors.
- **Incident Reports (`/reports`):** Auto-generated and exportable cybersecurity intelligence reports.
- **Audit Logs (`/logs`):** Access-controlled administrative audit trail of logins and system operations.
- **Administration & Users (`/settings`):** Analyst account approval, role management, and system preferences.
- **AI Security Assistant Chat:** Interactive contextual chat assistant powered by threat intelligence agent models.

## 🛠️ Development Setup

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

Server will run at `http://localhost:5173`.
